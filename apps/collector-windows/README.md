# Kantimitsu Benchmark Collector

A local-first Windows WPF utility that creates a small, user-reviewable JSON report for conversations about custom streaming automation.

- Every report category is an explicit checkbox.
- The report remains editable before saving.
- Report uploads do not exist in the collector.
- The optional network test contacts only `https://kantimitsu.com` and sends generated zero bytes.
- Sensitive identifiers, credentials, personal paths, arbitrary file lists and arbitrary process lists are out of scope.

The first public release is intentionally an unsigned beta. Windows may therefore show a SmartScreen warning; the collector page must state this plainly.
